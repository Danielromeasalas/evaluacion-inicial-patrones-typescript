¿Qué significa DAO?
¿Cuál es su responsabilidad principal?

    Su responsabilidad es que el usuario modificar o obtener informacion de la base de datos haciendo una llamada a un método concreto, de forma cómoda y rápida desde el propio main.


¿Qué relación tiene DAO con una base de datos?

    El DAO se realciona con la base de datos mediante un sistema de gestion de datos (como por ejemplo postgre), esto le permite modificar u obtener informacion de la base de datos, y que por consecuencia, el usuario pueda acceder también a esos privilegios.


¿Qué operaciones aparecen habitualmente en un DAO?

    Las principales opciones que puedes realizar utilizando DAO son de modificacion, agregación o eliminacion de datos. Además mediante consultas select puedes realizar operaciones como buscar campos por id, ver todos los campos, o hacer consultas básicas con condiciones personalizadas.
